Version 4.2 of Lumen Editor is available today for Windows and macOS. This release focuses on speed when working with large files and on a redesigned export panel.

Opening a RAW file is now about 40 percent faster on machines with 16 GB of memory. We changed how previews are cached, so scrolling through a folder of 500 images no longer stalls on the first pass. The brush tool also responds more quickly on 45-megapixel files, which was the most common complaint in the last survey.

The export panel has been rebuilt. It now remembers the last five export presets and shows an estimated file size before you save. You can export to JPEG, PNG, TIFF and the new AVIF format, and you can set a maximum long edge in pixels. Batch exports run in the background, so you can keep editing while they finish.

We fixed three bugs. Crop guides no longer disappear after you rotate an image by a small angle. Colour profiles are now kept when you export to TIFF. The undo history no longer resets when you switch between two open documents.

Version 4.2 requires Windows 10 or later, or macOS 12 or later. Support for macOS 11 ends with this release. Your existing catalogs open without conversion, but we recommend making a backup copy first.
